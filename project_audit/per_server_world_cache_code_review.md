## Complexity and state

Spatial ranks, fixed-depth ancestry and hashed lookup are O(1) in the supported
five-level terrain hierarchy. Frontier/tree queue updates are O(log F); anchor
movement reheapifies O(F). Initial filesystem/inventory discovery is linear in
files/regions, retained and incrementally updated. Validation is O(P+S) for palette
entries and fixed-section index cells, with no render-cell array on cache-only
work. Whole-file compaction is linear in current committed bindings/payload bytes.
These operations are not all O(1), and source review is not a throughput benchmark.
No new memory/CPU/request-rate budgets were introduced by this plan; selected
bandwidth/storage policy, structural validity checks and transport flow control
are distinct from arbitrary work governors.
