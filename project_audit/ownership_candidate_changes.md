Functional corrections in this candidate:

- Section jobs retain their original owner, content hash, model generation and
  purpose. Obsolete work is rejected before meshing, reclamation and upload.
- Reclamation first verifies that permitted victims provide enough space.
  Failed admission preserves the cache. Prepared-only work cannot evict useful
  revisit geometry. Eligibility totals avoid scanning the cache for every
  rejected job; capacity-dependent retries wake when capacity actually changes.
- Native meshing uses actual block positions with adjacent LOD cells for halo
  lighting and culling. Block entity inputs are prepared on the client thread.
  Detached entities are not inserted into the live world. Coarse AO does not
  reuse Minecraft's position-only lighting cache across different anchors.
- The explicit SourceCell vertex attribute preserves native normals. Native
  clipping uses actual drawable sections and a depth snapshot captured before
  Voxy drawing. A native surface must lie in the source cell before owning its
  opaque pixels. Depth copy failures retain coverage and are reported.
- Incomplete cached terrain probes with its known content hash. Matching server
  confirmation prevents repeated payload requests for an unchanged incomplete
  representation. Cache rendering never waits for this confirmation.
