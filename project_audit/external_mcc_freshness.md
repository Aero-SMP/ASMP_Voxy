Together these sources support the directory-time approach on the reported host; the exact installed kernel implementation and race behavior were not experimentally validated.

The limitations are explicit: in-place MCC edits by external tools can leave parent-directory time unchanged; coarse or non-multigrain filesystems can report equal times for separate mutations; deliberate timestamp restoration can defeat a timestamp fingerprint. Unrelated directory changes can trigger conservative extra source reads. This check is a freshness heuristic for the normal Minecraft save lifecycle, not a universal change journal or an atomic snapshot of a concurrently written world.
