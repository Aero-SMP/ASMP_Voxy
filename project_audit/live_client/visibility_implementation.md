# Camera quality and visibility implementation

Scope: production implementation and brief live verification on MGengine only. No integration tests or virtual-client load runs are used for this change. The server intentionally remains build252; client protocol and persisted payloads remain compatible.

- `ViewDemand.Camera` consumes the actual render projection, model-view, position and viewport. It checks section frustum bounds and ports the previous Voxy projected-area diameter with center weighting. Pixel size retains the previous64px default and28–256px logarithmic slider. Zoom changes the projection and desired hierarchy. Projected results are reused within the same camera snapshot.
- `DepthVisibility` builds a complete R32F maximum-depth mip hierarchy from current opaque depth. Odd viewport edges are included in each reduction. Batched bounds are GPU-tested against conservative mip footprints and nearest section depth. One fenced transaction is read only after completion; rejected results only affect demand when the camera snapshot still matches. Near-plane intersections are eligible. Drawn ancestors cannot reject the descendants needed to replace them.
- Selection keeps parent fallback until all required visible children are GPU-published; off-frustum siblings do not block activation. Actual drawing still uses current hardware depth testing.
- `TerrainSession` checks coordinate cache availability before requesting payloads, including visible coverage provided by finer cached descendants. Local decoding owns validation and can flag corrupt files for refill. A cached section awaiting CPU meshing is not downloaded again. Missing work progresses by natural hierarchy level. Freshness uses one in-flight request and yields when the requested view changes; sweeps have a5-second cadence. Unavailable records are rechecked by background reconciliation.
- Sodium has a compact Voxy settings page: rendering, distance and pixel target. Live controls support temporary pixel/FOV overrides for this single-player verification; removing the FOV property restores the original option.
