# Live pressure verification

Pressure verification is suspended by the user. Do not start the 100-client or
mutation-pressure runs until the user explicitly re-enables them. Current
acceptance uses the real PC and scoped existing-world observations.

The obsolete Python driver for the removed background-only connection has been
retired. The native `live_pressure` binary consumes the current authenticated
wire format for one supplied Minecraft-session route; it is not a 100-player
acceptance harness. A future pressure driver must register independent current
routes and share the same total-cap policy. No pressure result is claimed here.
